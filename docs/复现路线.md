# ASTGCN 复现路线

本文档给出手工复现 ASTGCN 的推荐顺序。目标是先跑通最小可用版本，再逐步补充工程化能力。

## 1. 第一阶段边界

第一阶段只复现：

- 数据集：PEMS04。
- 模型：ASTGCN recent component。
- 输入窗口：过去 12 个时间步。
- 预测窗口：未来 12 个时间步。
- 输入特征：第 0 个特征。
- 预测目标：第 0 个特征。

暂不实现：

- MSTGCN。
- daily component。
- weekly component。
- 多特征输入。
- 多特征输出。

## 2. 推荐实现顺序

### 第 1 步：配置读取

目标文件：

```text
configurations/PEMS04_astgcn.yaml
src/utils/config.py
```

要完成的事情：

- 读取 yaml 配置。
- 检查路径、节点数、时间窗口、模型参数是否存在。
- 将配置传递给后续模块。

核心变量：

| 变量 | 含义 |
| --- | --- |
| `num_of_vertices` | 节点数，PEMS04 为 307。 |
| `len_input` | 输入历史长度，第一阶段为 12。 |
| `num_for_predict` | 预测未来长度，第一阶段为 12。 |
| `in_channels` | 输入特征数，第一阶段为 1。 |
| `K` | Chebyshev 图卷积阶数。 |

验证方式：

```powershell
python scripts/train_astgcn.py --config configurations/PEMS04_astgcn.yaml
```

早期可以只打印配置，不训练。

### 第 2 步：数据预处理

目标文件：

```text
src/data/preprocessing.py
scripts/prepare_data.py
```

要完成的事情：

- 读取 `data/PEMS04/pems04.npz`。
- 根据时间索引生成监督样本。
- 划分训练集、验证集、测试集。
- 用训练集统计量标准化输入。
- 保存预处理结果。

推荐函数：

| 函数 | 职责 |
| --- | --- |
| `search_data` | 查找历史时间窗口。 |
| `get_sample_indices` | 生成单个样本的输入和目标。 |
| `generate_dataset` | 遍历全量数据生成样本集合。 |
| `standardize` | 使用训练集均值和标准差标准化。 |
| `save_dataset` | 保存 `.npz`。 |

验证重点：

```text
train_x: (B_train, 307, 1, 12)
train_target: (B_train, 307, 12)
```

### 第 3 步：数据加载

目标文件：

```text
src/data/dataset.py
```

要完成的事情：

- 读取预处理 `.npz`。
- 转成 PyTorch Tensor。
- 构造 `DataLoader`。

推荐函数：

| 函数 | 职责 |
| --- | --- |
| `load_processed_dataset` | 从 `.npz` 读取数组。 |
| `build_dataloader` | 构建 PyTorch DataLoader。 |

不要在这里做复杂预处理。数据切片应放在 `preprocessing.py`。

### 第 4 步：图结构计算

目标文件：

```text
src/graph/adjacency.py
src/graph/laplacian.py
```

要完成的事情：

- 从 `distance.csv` 构造邻接矩阵。
- 计算缩放拉普拉斯矩阵。
- 生成 `K` 阶 Chebyshev 多项式。

验证重点：

```text
adjacency: (307, 307)
scaled_laplacian: (307, 307)
cheb_polynomials: K 个 (307, 307) 矩阵
```

### 第 5 步：指标和损失

目标文件：

```text
src/metrics/losses.py
src/metrics/evaluation.py
```

要完成的事情：

- 写训练损失。
- 写测试指标。
- 支持 masked 与 unmasked 两类计算方式。

优先实现：

```text
MAE
MSE
RMSE
MAPE
masked MAE
masked MSE
```

### 第 6 步：模型层

目标文件：

```text
src/models/layers.py
src/models/astgcn.py
```

推荐顺序：

1. `TemporalAttention`
2. `SpatialAttention`
3. `ChebGraphConvWithAttention`
4. `ASTGCNBlock`
5. `ASTGCN`

验证重点：

```text
输入: (B, 307, 1, 12)
输出: (B, 307, 12)
```

### 第 7 步：训练流程

目标文件：

```text
src/engine/trainer.py
scripts/train_astgcn.py
```

要完成的事情：

- 初始化模型。
- 初始化优化器。
- 训练一个 epoch。
- 在验证集上计算 loss。
- 保存验证集最优权重。

第一轮调试建议：

```yaml
training:
  batch_size: 8
  epochs: 1
```

### 第 8 步：评估流程

目标文件：

```text
src/engine/evaluator.py
scripts/evaluate_astgcn.py
```

要完成的事情：

- 加载 `best.pt`。
- 对测试集预测。
- 输出 MAE、RMSE、MAPE。
- 保存预测结果。

## 3. 每阶段完成标准

| 阶段 | 完成标准 |
| --- | --- |
| 配置 | 能读取并打印全部关键变量。 |
| 数据预处理 | 能生成符合形状要求的 `.npz`。 |
| 数据加载 | 能得到 train/val/test DataLoader。 |
| 图结构 | 能得到 `K` 个 Chebyshev 多项式。 |
| 指标 | 能对随机张量计算指标。 |
| 模型 | 一个 batch 前向输出形状正确。 |
| 训练 | 能跑 1 个 epoch 并保存权重。 |
| 评估 | 能加载权重并输出测试指标。 |

## 4. 不建议的实现方式

- 不建议把数据预处理写进训练脚本。
- 不建议在模型文件里读取配置和数据。
- 不建议训练脚本里保存大量全局变量。
- 不建议一开始同时支持多个数据集。
- 不建议一开始实现 MSTGCN 和多特征预测。

## 5. 后续扩展路线

第一阶段跑通后，可以按以下顺序扩展：

1. 支持 PEMS08。
2. 支持多特征输入。
3. 加入 MSTGCN 对照模型。
4. 加入 daily 和 weekly component。
5. 增加预测曲线可视化。
6. 增加实验对比表格。
