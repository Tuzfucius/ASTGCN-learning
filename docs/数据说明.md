# 数据说明

本文档说明 PEMS04 数据集在本项目中的使用方式、变量含义和张量形状。

## 1. 数据文件

当前数据位于：

```text
data/PEMS04/
```

主要文件：

| 文件 | 说明 |
| --- | --- |
| `pems04.npz` | 原始交通时序数据。 |
| `distance.csv` | 交通节点之间的距离或连接关系。 |
| `PEMS04_r1_d0_w0_astcgn.npz` | 预处理后的 recent component 数据。 |

数据文件不提交到 git。

## 2. 原始数据含义

`pems04.npz` 通常包含名为 `data` 的数组。

可理解为：

```text
(时间长度, 节点数量, 特征数量)
```

其中：

- 时间长度：按 5 分钟采样得到的时间序列长度。
- 节点数量：PEMS04 为 307。
- 特征数量：原始数据通常包含多个交通相关特征。

第一阶段只使用第 0 个特征。

## 3. 图结构数据

`distance.csv` 用于构造交通图。

图结构变量：

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| `adjacency` | `(307, 307)` | 邻接矩阵。 |
| `distance_mx` | `(307, 307)` | 距离矩阵，可选。 |
| `scaled_laplacian` | `(307, 307)` | 缩放拉普拉斯矩阵。 |
| `cheb_polynomials` | `K * (307, 307)` | Chebyshev 多项式列表。 |

图结构用于 ASTGCN 的图卷积部分，让节点预测不仅依赖自身历史值，也依赖相邻节点信息。

## 4. 监督样本定义

第一阶段任务：

```text
过去 12 个时间步 -> 未来 12 个时间步
```

输入：

```text
x: (B, N, F, T)
```

目标：

```text
y: (B, N, T_pred)
```

对于 PEMS04：

```text
x: (B, 307, 1, 12)
y: (B, 307, 12)
```

变量含义：

| 变量 | 含义 |
| --- | --- |
| `B` | batch size。 |
| `N` | 节点数量，PEMS04 为 307。 |
| `F` | 输入特征数，第一阶段为 1。 |
| `T` | 输入历史时间步，第一阶段为 12。 |
| `T_pred` | 预测未来时间步，第一阶段为 12。 |

## 5. 预处理过程

预处理流程：

```text
读取原始 data
  -> 根据 label_start_idx 生成历史窗口
  -> 生成预测目标
  -> 划分 train/val/test
  -> 使用训练集统计量标准化输入
  -> 保存 .npz
```

建议划分比例：

```text
train: 60%
val: 20%
test: 20%
```

## 6. 预处理结果变量

预处理后的 `.npz` 建议包含：

| 变量 | 形状 | 说明 |
| --- | --- | --- |
| `train_x` | `(B_train, 307, 1, 12)` | 训练输入。 |
| `train_target` | `(B_train, 307, 12)` | 训练目标。 |
| `train_timestamp` | `(B_train, 1)` | 训练样本时间索引。 |
| `val_x` | `(B_val, 307, 1, 12)` | 验证输入。 |
| `val_target` | `(B_val, 307, 12)` | 验证目标。 |
| `val_timestamp` | `(B_val, 1)` | 验证样本时间索引。 |
| `test_x` | `(B_test, 307, 1, 12)` | 测试输入。 |
| `test_target` | `(B_test, 307, 12)` | 测试目标。 |
| `test_timestamp` | `(B_test, 1)` | 测试样本时间索引。 |
| `mean` | `(1, 1, 1, 1)` | 训练集输入均值。 |
| `std` | `(1, 1, 1, 1)` | 训练集输入标准差。 |

## 7. 标准化规则

只用训练集计算：

```text
mean = train_x.mean(...)
std = train_x.std(...)
```

然后用于：

```text
train_x_norm = (train_x - mean) / std
val_x_norm = (val_x - mean) / std
test_x_norm = (test_x - mean) / std
```

不要分别用验证集或测试集计算自己的均值和标准差，否则会造成数据泄漏。

## 9. 常见错误

- 把原始 3 个特征都输入模型，但配置仍写 `in_channels = 1`。
- 目标张量保留了特征维，导致输出和标签形状不一致。
- 用测试集统计量标准化测试集。
- 邻接矩阵节点数和数据节点数不一致。
- 把 `B, N, F, T` 写成 `B, T, N, F`。
