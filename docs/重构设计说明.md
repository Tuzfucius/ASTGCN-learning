# 重构设计说明

本文档说明为什么要重构官方 ASTGCN 项目，以及本项目的代码架构设计。

## 1. 重构目标

本项目重构目标：

- 保留 ASTGCN 核心算法。
- 简化官方项目中耦合较强的脚本结构。
- 让每个目录和文件职责更清晰。
- 便于手工复现、课堂展示和后续扩展。

重构不是为了改变论文方法，而是为了降低阅读和维护成本。

## 2. 官方结构的主要问题

官方项目适合快速运行，但对手工复现不够友好，主要体现在：

- 训练脚本中包含大量全局变量。
- 数据加载、验证、预测保存等逻辑集中在 `utils.py`。
- 模型、训练和实验目录管理耦合较强。
- 初学者很难从文件结构直接理解数据流和模型流。

## 3. 新架构分层

推荐结构：

```text
configurations/
data/
docs/
src/
  data/
  graph/
  metrics/
  models/
  engine/
  utils/
scripts/
experiments/
```

分层原则：

| 层 | 目录 | 责任 |
| --- | --- | --- |
| 配置层 | `configurations/` | 管理实验变量。 |
| 数据层 | `src/data/` | 预处理和加载数据。 |
| 图结构层 | `src/graph/` | 构造邻接矩阵和图卷积所需矩阵。 |
| 指标层 | `src/metrics/` | 损失函数和评估指标。 |
| 模型层 | `src/models/` | ASTGCN 网络结构。 |
| 引擎层 | `src/engine/` | 训练和评估流程。 |
| 工具层 | `src/utils/` | 配置、日志、随机种子等通用功能。 |
| 脚本层 | `scripts/` | 命令行入口。 |

## 4. 数据流

```text
data/PEMS04/pems04.npz
  -> src/data/preprocessing.py
  -> data/PEMS04/PEMS04_r1_d0_w0_astcgn.npz
  -> src/data/dataset.py
  -> DataLoader
  -> src/engine/trainer.py
```

数据层只负责把原始数据变成模型可消费的张量。

## 5. 图结构流

```text
data/PEMS04/distance.csv
  -> src/graph/adjacency.py
  -> adjacency matrix
  -> src/graph/laplacian.py
  -> scaled Laplacian
  -> Chebyshev polynomials
  -> src/models/layers.py
```

图结构层不负责训练，也不负责读取模型配置之外的业务逻辑。

## 6. 模型流

```text
input x
  -> TemporalAttention
  -> SpatialAttention
  -> ChebGraphConvWithAttention
  -> ASTGCNBlock
  -> ASTGCN
  -> prediction
```

模型层只处理张量计算。

不应放入模型层的内容：

- 数据路径。
- 配置文件读取。
- 训练循环。
- 指标保存。
- 命令行参数解析。

## 7. 训练流

```text
scripts/train_astgcn.py
  -> src/utils/config.py
  -> src/data/dataset.py
  -> src/graph/*
  -> src/models/astgcn.py
  -> src/engine/trainer.py
  -> experiments/
```

脚本层只做入口，引擎层负责流程。

## 8. 文件命名原则

- 文件名使用小写英文和下划线。
- 类名使用清晰的模型概念，例如 `ASTGCNBlock`。
- 函数名使用动词开头，例如 `load_config`、`build_dataloader`。
- 文档名使用中文，便于作业阅读。

## 9. 变量命名原则

优先使用模型论文和官方代码中常见变量：

| 变量 | 含义 |
| --- | --- |
| `num_of_vertices` | 节点数。 |
| `num_for_predict` | 预测步数。 |
| `len_input` | 输入步数。 |
| `in_channels` | 输入特征通道数。 |
| `K` | Chebyshev 阶数。 |
| `nb_block` | block 数量。 |
| `nb_chev_filter` | 图卷积通道数。 |
| `nb_time_filter` | 时间卷积通道数。 |

不要把同一个变量在不同文件中改成多个名字。

## 10. 可扩展方向

第一阶段完成后，可以扩展：

- 新增 `src/models/mstgcn.py` 实现 MSTGCN。
- 新增 PEMS08 配置文件。
- 支持多特征输入。
- 支持 daily 和 weekly component。
- 增加可视化脚本。
- 增加实验对比文档。

## 11. 判断代码是否合格

一个模块是否写得清晰，可以用以下问题检查：

- 这个文件是否只做一类事情。
- 输入输出形状是否清楚。
- 是否可以单独测试。
- 是否依赖了不该依赖的上层模块。
- 是否能通过文件名看出职责。

如果答案不清楚，应优先拆分或补充文档。
