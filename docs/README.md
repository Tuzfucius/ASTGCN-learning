## 维护原则

- 新增文档后，先在本文件中补充链接。
- 文档标题应直接说明用途，避免使用含义不清的名称。
- 文档内容不要把未完成的功能写成已经完成。
- 涉及代码行为时，应尽量写清楚真实文件名、函数名和张量形状。
