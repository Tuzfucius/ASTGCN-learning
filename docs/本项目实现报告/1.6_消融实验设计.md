# 1.6 消融实验设计

## 1.6.1 控制变量

你提到的“实验采用控制变量法，即保持数据集划分、输入窗口长度、预测步长、优化器、学习率和训练轮数等设置不变”，在当前项目中的具体固定参数如下：

| 类别 | 固定参数 |
|---|---|
| 数据集 | `PEMS04` |
| 数据路径 | `data/raw/PEMS04/pems04.npz` |
| 图文件 | `data/raw/PEMS04/distance.csv` |
| 节点数 | `307` |
| 输入特征维度 | `3` |
| 目标通道 | `0` |
| 每天采样点数 | `288` |
| 训练 / 验证 / 测试划分 | `0.6 / 0.2 / 0.2` |
| recent 长度 | `12` |
| daily 天数 | `1` |
| weekly 周数 | `1` |
| 预测步长 | `12` |
| 图设置 | `directed = false`, `weighted = false`, `cheb_order = 3` |
| 模型结构 | `num_blocks = 2`, `hidden_channels = 64`, `time_kernel_size = 3` |
| batch size | `32` |
| 优化器 | `Adam` |
| 学习率 | `0.001` |
| 权重衰减 | `0.0001` |
| 损失函数 | `mae` |
| 随机种子 | `42` |
| 早停耐心 | `10` |
| 消融正式训练轮数 | `10` |

在 `outputs/ablation-cloud-training.ipynb` 中，正式消融使用的是 `RUN_MODE = "full"`，即：

$$
\text{epochs} = 10,\qquad \text{max\_batches} = None.
$$

快速调试模式 `quick` 仅用于连通性检查，对应：

$$
\text{epochs} = 1,\qquad \text{max\_batches} = 2.
$$

## 1.6.2 消融变量

当前 notebook 定义的实验变量如下：

| 实验名称 | 变化项 |
|---|---|
| `full_astgcn` | 无变化 |
| `recent_only` | `use_daily = False`, `use_weekly = False` |
| `no_temporal_attention` | `use_temporal_attention = False` |
| `no_spatial_attention` | `use_spatial_attention = False` |
| `identity_graph` | `graph_mode = "identity"` |

其余配置保持不变。实验中还固定了每个实验独立的输出目录：

1. `outputs/ablation_cloud/<experiment>/checkpoints`
2. `outputs/ablation_cloud/<experiment>/logs`
3. `outputs/ablation_cloud/<experiment>/predictions`

## 1.6.3 消融结果

当前 notebook 中的测试结果如下：

| 实验 | best_val_mae | test_mae | test_rmse | test_mape |
|---|---:|---:|---:|---:|
| full_astgcn | 0.135544 | 22.044945 | 35.672867 | 1905319.375 |
| recent_only | 0.144014 | 22.723455 | 35.022690 | 1313689.500 |
| no_temporal_attention | 0.135867 | 22.023161 | 35.615143 | 1832686.875 |
| no_spatial_attention | 0.132057 | 21.268803 | 33.801922 | 1610077.500 |
| identity_graph | 0.135601 | 22.059681 | 35.675758 | 1911414.000 |

相对于完整模型的变化率如下：

| 实验 | test_mae 变化率 | test_rmse 变化率 | test_mape 变化率 |
|---|---:|---:|---:|
| recent_only | `+3.077852%` | `-1.822609%` | `-31.051481%` |
| no_temporal_attention | `-0.098816%` | `-0.161815%` | `-3.812091%` |
| no_spatial_attention | `-3.520726%` | `-5.244728%` | `-15.495663%` |
| identity_graph | `+0.066846%` | `+0.008106%` | `+0.319874%` |

## 1.6.4 解释

1. `recent_only` 的结果高于完整模型，说明周期分支仍提供有效信息。
2. `no_temporal_attention` 与完整模型接近，说明时间注意力在当前设置下带来的增益有限。
3. `no_spatial_attention` 的结果更低，但该现象需要在更长训练和多随机种子条件下复核。
4. `identity_graph` 与完整模型接近，说明图结构在当前配置中没有显示出非常强的边际优势。

因此，消融结果适合用于结构贡献分析，但不宜仅基于单次运行下绝对值下结论。

## 1.6.5 实现依据

1. `src/astgcn/models/ablation.py` 定义消融开关。
2. `scripts/train.py` 和 notebook 负责加载配置并构造模型。
3. `outputs/ablation-cloud-training.ipynb` 负责批量运行实验、保存预测与统计结果。
