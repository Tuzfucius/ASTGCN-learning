# 1.4 模型训练流程

## 1.4.1 训练入口与配置文件

训练入口为 `scripts/train.py`。训练流程由 `configs/pems04.yaml` 驱动，读取的关键配置如下：

| 配置项 | 值 |
|---|---:|
| `batch_size` | `32` |
| `epochs` | `50` |
| `learning_rate` | `0.001` |
| `weight_decay` | `0.0001` |
| `optimizer` | `Adam` |
| `loss` | `mae` |
| `early_stop_patience` | `10` |
| `seed` | `42` |
| `num_blocks` | `2` |
| `hidden_channels` | `64` |
| `cheb_order` | `3` |
| `time_kernel_size` | `3` |

## 1.4.2 标准训练过程

`Trainer.fit()` 的基本过程如下：

1. 进入训练模式；
2. 前向传播得到预测值；
3. 使用 MAE 损失优化参数；
4. 在验证集上计算验证指标；
5. 若验证 MAE 更优，则保存 `best.pt`；
6. 若连续多个 epoch 未改善，则触发早停。

训练目标写为：

$$
\mathcal{L}_{\text{MAE}}
=
\frac{1}{BNP}\sum_{b=1}^{B}\sum_{n=1}^{N}\sum_{p=1}^{P}
\left|\hat{Y}_{bnp}-Y_{bnp}\right|.
$$

## 1.4.3 checkpoint 管理

训练保存的 checkpoint 包含：

1. 模型参数
2. 优化器状态
3. epoch 编号
4. 最优验证指标
5. 配置字典
6. 标准化器参数

对应文件为 `outputs/checkpoints/best.pt`。当前生成的 checkpoint 文件大小约为 `16,493,242` 字节。

## 1.4.4 推理与测试

`scripts/infer.py` 负责：

1. 加载 `best.pt`
2. 在测试集上反标准化后计算指标
3. 保存预测数组到 `outputs/predictions/test_predictions.npz`

预测结果保存内容包括：

1. `prediction`
2. `target`
3. `t0`

若启用 `save_components`，还会保存各分支输出。

## 1.4.5 云端 notebook 训练参数

`outputs/ablation-cloud-training.ipynb` 中给出的运行参数为：

| 参数 | 值 |
|---|---:|
| `RUN_MODE` | `full` |
| `FULL_EPOCHS` | `10` |
| `QUICK_EPOCHS` | `1` |
| `FULL_MAX_BATCHES` | `None` |
| `QUICK_MAX_BATCHES` | `2` |
| `DEVICE` | `cuda` 或 `cpu`，取决于环境 |

因此，正式消融实验采用的训练轮数是 `10`，并未启用 batch 截断。

## 1.4.6 训练流程伪代码

```text
Input: config, train_loader, val_loader, model
for epoch = 1..epochs do
    for batch in train_loader do
        pred <- model(batch)
        loss <- MAE(pred, target)
        backward and update
    end for

    val_metric <- evaluate(val_loader)
    if val_metric improves then
        save checkpoint
    end if

    if patience reached then
        stop
    end if
end for
```
