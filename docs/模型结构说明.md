# ASTGCN 模型结构说明

本文档说明 ASTGCN 在本项目中的代码架构、变量含义和张量流向。

## 1. 模型输入输出

第一阶段输入：

```text
x: (B, N, F, T)
```

对于 PEMS04：

```text
x: (B, 307, 1, 12)
```

模型输出：

```text
y_hat: (B, N, T_pred)
```

对于 PEMS04：

```text
y_hat: (B, 307, 12)
```

变量含义：

| 变量 | 含义 |
| --- | --- |
| `B` | batch size。 |
| `N` | 节点数量。 |
| `F` | 输入特征通道数。 |
| `T` | 输入历史时间步。 |
| `T_pred` | 预测未来时间步。 |

## 2. 模型整体链路

ASTGCN recent component 的整体链路：

```text
输入历史序列 x
  -> TemporalAttention
  -> SpatialAttention
  -> ChebGraphConvWithAttention
  -> 时间卷积
  -> 残差连接
  -> LayerNorm
  -> 多个 ASTGCNBlock 堆叠
  -> final convolution
  -> 未来多步预测
```

## 3. 代码文件规划

| 文件 | 职责 |
| --- | --- |
| `src/models/layers.py` | 存放模型基础层和 ASTGCN block。 |
| `src/models/astgcn.py` | 存放完整 ASTGCN 模型和构造函数。 |
| `src/graph/adjacency.py` | 构造邻接矩阵。 |
| `src/graph/laplacian.py` | 构造缩放拉普拉斯矩阵和 Chebyshev 多项式。 |

模型文件不负责读取数据和配置文件。

## 4. 核心类设计

### `TemporalAttention`

作用：

学习不同历史时间步之间的重要性。

输入：

```text
x: (B, N, F, T)
```

输出：

```text
temporal_attention: (B, T, T)
```

含义：

- 每个 batch 样本生成一个时间注意力矩阵。
- 矩阵描述历史时间步之间的相关性。

### `SpatialAttention`

作用：

学习不同交通节点之间的动态相关性。

输入：

```text
x: (B, N, F, T)
```

输出：

```text
spatial_attention: (B, N, N)
```

含义：

- 每个 batch 样本生成一个空间注意力矩阵。
- 矩阵描述节点之间的动态影响关系。

### `ChebGraphConvWithAttention`

作用：

结合 Chebyshev 图卷积和空间注意力提取空间特征。

输入：

```text
x: (B, N, F, T)
spatial_attention: (B, N, N)
cheb_polynomials: K 个 (N, N)
```

输出：

```text
spatial_gcn_output: (B, N, C_cheb, T)
```

变量：

| 变量 | 含义 |
| --- | --- |
| `K` | Chebyshev 多项式阶数。 |
| `C_cheb` | 图卷积输出通道数，即 `nb_chev_filter`。 |

### `ASTGCNBlock`

作用：

组合时间注意力、空间注意力、图卷积、时间卷积、残差连接和归一化。

输入：

```text
x: (B, N, F_in, T)
```

输出：

```text
block_output: (B, N, C_time, T_out)
```

核心组成：

- `TemporalAttention`
- `SpatialAttention`
- `ChebGraphConvWithAttention`
- `time_conv`
- `residual_conv`
- `LayerNorm`

### `ASTGCN`

作用：

堆叠多个 `ASTGCNBlock`，输出未来多步预测。

输入：

```text
x: (B, N, 1, 12)
```

输出：

```text
y_hat: (B, N, 12)
```

构造参数：

| 参数 | 含义 |
| --- | --- |
| `nb_block` | block 数量。 |
| `in_channels` | 输入特征数。 |
| `K` | Chebyshev 阶数。 |
| `nb_chev_filter` | 图卷积输出通道数。 |
| `nb_time_filter` | 时间卷积输出通道数。 |
| `num_for_predict` | 输出预测时间步。 |
| `len_input` | 输入历史时间步。 |
| `num_of_vertices` | 节点数量。 |

## 5. 图结构变量

ASTGCN 使用图结构表达交通节点之间的空间关系。

| 变量 | 形状 | 来源 |
| --- | --- | --- |
| `adj_mx` | `(N, N)` | `distance.csv`。 |
| `scaled_laplacian` | `(N, N)` | 邻接矩阵计算。 |
| `cheb_polynomials` | `K * (N, N)` | 缩放拉普拉斯矩阵递推。 |

Chebyshev 多项式递推关系：

```text
T_0 = I
T_1 = L_tilde
T_k = 2 * L_tilde * T_{k-1} - T_{k-2}
```

## 6. 推荐实现顺序

1. 先写 `TemporalAttention`，只验证输出 `(B, T, T)`。
2. 再写 `SpatialAttention`，只验证输出 `(B, N, N)`。
3. 写 `ChebGraphConvWithAttention`，验证通道转换。
4. 写 `ASTGCNBlock`，验证 block 输出形状。
5. 写 `ASTGCN`，验证完整模型输出 `(B, N, T_pred)`。

## 7. 不应放在模型层的内容

以下内容不应写进 `src/models/`：

- 配置文件读取。
- 原始数据读取。
- DataLoader 构造。
- 训练循环。
- 测试指标保存。
- 实验目录管理。

模型层只关心张量计算。
