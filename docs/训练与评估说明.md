# 训练与评估说明

本文档说明 ASTGCN 手工复现项目的训练流程、评估流程、变量含义和输出目录。

## 1. 入口脚本

建议保留三个脚本入口：

| 文件 | 职责 |
| --- | --- |
| `scripts/prepare_data.py` | 数据预处理入口。 |
| `scripts/train_astgcn.py` | 训练入口。 |
| `scripts/evaluate_astgcn.py` | 测试评估入口。 |

脚本只负责解析命令行参数和调用 `src/` 中的模块，不写核心算法。

## 2. 数据预处理命令

建议命令：

```powershell
python scripts/prepare_data.py --config configurations/PEMS04_astgcn.yaml
```

预处理阶段输入：

```text
data/PEMS04/pems04.npz
data/PEMS04/distance.csv
```

预处理阶段输出：

```text
data/PEMS04/PEMS04_r1_d0_w0_astcgn.npz
```

## 3. 训练命令

建议命令：

```powershell
python scripts/train_astgcn.py --config configurations/PEMS04_astgcn.yaml
```

训练流程：

```text
读取配置
  -> 固定随机种子
  -> 加载 DataLoader
  -> 构造邻接矩阵
  -> 构造 Chebyshev 多项式
  -> 构造 ASTGCN 模型
  -> 训练
  -> 验证
  -> 保存最优模型
```

当前代码已实现：

- `src/engine/trainer.py` 负责 `fit`、`train_one_epoch`、`validate`、`save_checkpoint`。
- `scripts/train_astgcn.py` 负责读取配置、构造 DataLoader、图结构、模型、Adam optimizer 和 loss。
- 当配置为 `cuda` 但 CUDA 不可用时，训练器会自动回退到 CPU。
- 最优验证集权重保存为 `best.pt`。

## 4. 评估命令

建议命令：

```powershell
python scripts/evaluate_astgcn.py --config configurations/PEMS04_astgcn.yaml --model experiments/PEMS04/astgcn_recent/best.pt
```

评估流程：

```text
读取配置
  -> 加载测试集
  -> 加载模型权重
  -> 执行预测
  -> 反标准化
  -> 计算指标
  -> 保存预测结果
```

当前代码已实现：

- `src/engine/evaluator.py` 负责加载 checkpoint、测试集预测、指标计算和保存预测结果。
- `scripts/evaluate_astgcn.py` 会保存 `metrics.json`。
- 如果 `output.save_predictions` 为 `true`，会保存 `predictions.npz`。

注意：第一阶段只标准化输入 `x`，`target` 保留原始数值，因此评估阶段直接对模型输出和标签计算指标，不需要对预测值做反标准化。

## 5. 训练变量说明

| 变量 | 含义 |
| --- | --- |
| `batch_size` | 每次训练输入的样本数量。 |
| `epochs` | 完整遍历训练集的次数。 |
| `start_epoch` | 断点训练时的起始 epoch。 |
| `learning_rate` | 优化器学习率。 |
| `loss_function` | 训练损失函数。 |
| `metric_method` | 评估是否忽略缺失值。 |
| `missing_value` | 缺失值标识。 |
| `device` | `cuda` 或 `cpu`。 |
| `seed` | 随机种子。 |

## 6. 模型变量说明

| 变量 | 含义 |
| --- | --- |
| `nb_block` | ASTGCN block 数量。 |
| `K` | Chebyshev 图卷积阶数。 |
| `nb_chev_filter` | 图卷积输出通道数。 |
| `nb_time_filter` | 时间卷积输出通道数。 |
| `time_strides` | 时间卷积步幅。 |
| `num_for_predict` | 预测未来时间步。 |

## 7. 损失函数和指标

当前指标代码已实现于：

```text
src/metrics/losses.py
src/metrics/evaluation.py
```

训练阶段可选：

| 名称 | 说明 |
| --- | --- |
| `mse` | 均方误差。 |
| `mae` | 平均绝对误差。 |
| `masked_mse` | 忽略缺失值的 MSE。 |
| `masked_mae` | 忽略缺失值的 MAE。 |
| `masked_rmse` | 忽略缺失值的 RMSE。 |

`get_loss_function(loss_name, missing_value)` 会根据配置返回训练使用的 loss 函数。
普通 `mse` 和 `mae` 使用 PyTorch 内置损失；masked 版本只统计标签中非缺失值的位置。

评估阶段建议输出：

| 指标 | 含义 |
| --- | --- |
| `MAE` | 平均绝对误差。 |
| `RMSE` | 均方根误差。 |
| `MAPE` | 平均绝对百分比误差。 |

评估阶段通过 `metric_method` 控制是否忽略缺失值：

| `metric_method` | 行为 |
| --- | --- |
| `unmask` | MAE/RMSE 直接统计全部位置，MAPE 会跳过真实值接近 0 的位置以避免除零。 |
| `mask` | MAE/RMSE/MAPE 都忽略 `missing_value` 对应的位置。 |

MAPE 沿用官方项目的数值尺度，不额外乘以 100。

## 8. 实验目录

推荐输出结构：

```text
experiments/
  PEMS04/
    astgcn_recent/
      config.yaml
      best.pt
      metrics.json
      predictions.npz
      train.log
```

文件说明：

| 文件 | 说明 |
| --- | --- |
| `config.yaml` | 本次实验使用的配置副本。 |
| `best.pt` | 验证集表现最好的模型权重。 |
| `metrics.json` | 测试集指标。 |
| `predictions.npz` | 预测值和真实值。 |
| `train.log` | 训练日志。 |

当前 `best.pt` 内容：

| 字段 | 说明 |
| --- | --- |
| `epoch` | 保存权重对应的 epoch，下标从 0 开始。 |
| `val_loss` | 当前最优验证 loss。 |
| `model_state_dict` | 模型参数。 |
| `optimizer_state_dict` | 优化器状态。 |

## 9. `Trainer` 职责

`src/engine/trainer.py` 建议封装：

```text
Trainer.fit()
Trainer.train_one_epoch()
Trainer.validate()
Trainer.save_checkpoint()
```

`Trainer` 应接收外部传入的模型、数据加载器、损失函数和优化器，不应自己读取原始数据。

当前已实现以上方法。

## 10. `Evaluator` 职责

`src/engine/evaluator.py` 建议封装：

```text
Evaluator.predict()
Evaluator.evaluate()
Evaluator.save_predictions()
```

`Evaluator` 应负责测试阶段推理和指标计算，不负责训练。

当前已实现以上方法，并额外提供 `save_predictions()` 保存预测数组。

## 11. 最小调试配置

初次调试建议临时使用：

```yaml
training:
  batch_size: 8
  epochs: 1
  device: cpu
```

如果 CPU 能跑通，再切换到 GPU。

## 12. 常见问题

### loss 能计算但指标异常

优先检查：

- 预测值是否反标准化。
- 标签是否是真实值。
- `metric_method` 是否与缺失值设置一致。
- `MAPE` 是否因为真实值中存在 0 而被大量位置过滤。

### 输出形状不匹配

优先检查：

```text
model output: (B, N, T_pred)
target: (B, N, T_pred)
```

### GPU 不可用

允许先使用：

```yaml
device: cpu
```

保证逻辑正确后再处理 GPU 环境。
