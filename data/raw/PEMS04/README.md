# PEMS04 数据说明

本目录保存 PEMS04 数据集相关文件。

## 数据集基本信息

| 项目 | 说明 |
| --- | --- |
| 数据集名称 | PEMS04 |
| 节点数量 | 307 |
| 采样间隔 | 5 分钟 |
| 每小时采样点 | 12 |
| 第一阶段输入特征数 | 1 |
| 第一阶段预测目标 | 第 0 个特征的未来值 |

## 当前任务定义

第一阶段任务固定为：

```text
所有节点过去 12 个时间步的第 0 个特征
预测
所有节点未来 12 个时间步的第 0 个特征
```

输入形状：

```text
(B, 307, 1, 12)
```

输出形状：

```text
(B, 307, 12)
```

## 文件说明

| 文件 | 是否进入 git | 说明 |
| --- | --- | --- |
| `pems04.npz` | 否 | 原始图信号矩阵。 |
| `distance.csv` | 否 | 节点距离文件，用于构造邻接矩阵。 |
| `PEMS04_r1_d0_w0_astcgn.npz` | 否 | 官方预处理命名风格下的 recent component 数据。 |
| `README.md` | 是 | 本说明文件。 |

## 预处理文件变量

预处理后的 `.npz` 建议包含：

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| `train_x` | `(B_train, 307, 1, 12)` | 训练输入。 |
| `train_target` | `(B_train, 307, 12)` | 训练目标。 |
| `train_timestamp` | `(B_train, 1)` | 训练样本时间索引。 |
| `val_x` | `(B_val, 307, 1, 12)` | 验证输入。 |
| `val_target` | `(B_val, 307, 12)` | 验证目标。 |
| `val_timestamp` | `(B_val, 1)` | 验证样本时间索引。 |
| `test_x` | `(B_test, 307, 1, 12)` | 测试输入。 |
| `test_target` | `(B_test, 307, 12)` | 测试目标。 |
| `test_timestamp` | `(B_test, 1)` | 测试样本时间索引。 |
| `mean` | `(1, 1, 1, 1)` | 训练集均值。 |
| `std` | `(1, 1, 1, 1)` | 训练集标准差。 |

如果后续改为多特征输入，`train_x` 的第三维可以从 `1` 扩展为更多特征数，但第一阶段不建议扩展。
